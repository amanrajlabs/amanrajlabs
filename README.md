### 🖥️ Mac apps

| App | What it does | Download |
|---|---|---|
| **[Dockette](https://github.com/amanrajlabs/Dockette)** | Multiple floating docks: put a dock on any screen or edge, with apps, folders and widgets. | [Latest release](https://github.com/amanrajlabs/Dockette/releases/latest) |
| **[MacRing](https://github.com/amanrajlabs/MacRing)** | Radial quick-launcher: hold ⌥⇧ anywhere, then slide to an app, file, URL or shortcut. | [Latest release](https://github.com/amanrajlabs/MacRing/releases/latest) |
| **[NotchDeck](https://github.com/amanrajlabs/NotchDeck)** | Turns the MacBook notch into a dashboard: media, calendar, timers, file drops and window snapping. | [Latest release](https://github.com/amanrajlabs/NotchDeck/releases/latest) |

All three are written in Swift, run on Apple Silicon and Intel, and have no accounts, ads or analytics. Each README explains how to install and first launch it.
